# Abhishek Vijayvergiya Portfolio Website

This repository contains my personal portfolio website built with React, TypeScript, and Three.js.

Feel free to explore the code and use it for learning and inspiration.

---

## ⚙️ Project Details

- Personal portfolio website for showcasing skills, projects, and contact information
- Built with Vite, React, TypeScript, GSAP, and Three.js
- Includes custom scroll animations and a 3D character scene

---

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
